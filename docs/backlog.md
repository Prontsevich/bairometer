# Fallback Backlog

Use this file only when Linear is not configured or is temporarily unavailable.
It is a cheap intake and pending-synchronization record, not a parallel live
tracker.

Capture new ideas, reports, observations, and agent-discovered concerns here
before implementation. Mark entries created during a temporary outage as
`Pending Linear synchronization`. Do not start implementation directly from
this raw intake.

After Linear access returns, search for the canonical Issue, reconcile each
pending entry, and remove the temporary record. Keep this file available for
fallback use, but leave active work, status, priority, dependencies, and
acceptance in Linear while it is available.
