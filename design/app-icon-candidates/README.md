# Bairometer App Icon Candidates

This tracked archive preserves the six original directions and the final
selected hybrid from the 2026-07 icon exploration. It is a design reference
only and is not packaged into `AILimitBar.app`.

## Original Directions

1. `limit-rail-hard-stop.png` — Limit Rail 1: Hard Stop
2. `limit-rail-counterweight.png` — Limit Rail 2: Counterweight
3. `limit-rail-cutout.png` — Limit Rail 3: Cutout Boundary
4. `terminal-fieldset-legend-gap.png` — Terminal Fieldset 1: Legend Gap
5. `terminal-fieldset-stacked.png` — Terminal Fieldset 2: Stacked Accounts
6. `terminal-fieldset-corner-cut.png` — Terminal Fieldset 3: Corner Cut

## Selected Direction

`terminal-fieldset-rail-bars-soft-corners.png` is the selected application
icon direction. The packaged asset is derived from this design and lives in
`Resources/Assets.xcassets/AppIcon.appiconset/`.
